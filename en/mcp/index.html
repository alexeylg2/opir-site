MCP

Connecting an outside assistant

Opir has a built-in MCP server. Through it Claude Desktop, Claude Code or another client sees the open schematic and can change it — just as the built-in assistant does.

What you need

  • Opir is running, and Allow AI Access (MCP) is turned on in the Opir menu. Access is off by default.
  • A client that speaks MCP over stdio: Claude Desktop, Claude Code and others.

The server listens on 127.0.0.1 only — it cannot be reached from the network. The client starts a small program, opir mcp, which passes its requests to the app.

Steps

  1. Turn access on

    The menu Opir → Allow AI Access (MCP). The same switch is in Settings, under External AI clients.

  2. Add the server to the client

    Claude Code — one command in the terminal:

    claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp

    Claude Desktop — add this to the file ~/Library/Application Support/Claude/claude_desktop_config.json:

    {
  "mcpServers": {
    "opir": {
      "command": "/Applications/Opir.app/Contents/Helpers/opir",
      "args": ["mcp"]
    }
  }
}

    Then restart the client.

  3. Check

    Open a schematic in Opir and ask the client: “Which documents are open in Opir?” It should name your document.

What the client can do

Reads

The schematic with its parts, pins and nets; check results; a picture of the sheet; the netlist; the parts list; a switchboard’s table of groups; a part’s datasheet.

Changes

Adds and moves parts, joins pins with nets, names nets, sets wire sections and colours, adds sheets, a parts list and a table of groups.

The rules

  • Every call is one undo step. What changed is highlighted on the sheet; ⌘Z puts it back.
  • A person draws the wires. The client joins pins with nets, shown as dashed lines. Wire them by hand or with the Route Net command.
  • The client invents no symbols. If the library lacks a part, it says what is missing instead of drawing a stand-in.
  • It learns of others’ edits. If you or the built-in assistant changed the schematic between its calls, the server’s next answer opens with a list of the changes.
  • A file on disk will do too. The client can work with an .opir document by its path, even when the app is closed.

If it does not work

  • “Opir is not reachable” — the app is not running, or access is off in the Opir menu.
  • The client does not see the server — check the path to opir in the client’s settings and restart it.
