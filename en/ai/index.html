Claude Desktop, Claude Code and other MCP clients

Your AI app
works right in Opir.

Opir has a built-in MCP server. Through it Claude Desktop, Claude Code or any other app that speaks MCP sees your schematics and works with them: reads, checks, edits, brings several documents together, all in the conversation you are used to.

How to connect An example
What it gives you

The schematic becomes part of your AI conversation

Opir’s built-in assistant sees the open document. An outside app sees more: several documents, files on disk and its own other tools.

Your subscription, your model

Work with the Claude you already pay for, in Claude Desktop or Claude Code: no separate API key in Opir is needed for it.

Many documents at once

The assistant opens .opir files on disk even when Opir is closed: go through a folder, check every schematic, combine the parts lists.

Together with other tools

In the same conversation, whatever your client can do: web search, spreadsheets, files, other MCP servers. Find a part, sum up the purchase, write notes from the drawing.

Edits show at once

Changes appear in the open document. What changed is highlighted, and each call is one undo step: ⌘Z puts it back.

Several assistants together

The built-in assistant and outside clients connected at the same time learn of each other’s edits.

Only on your Mac

The server listens on 127.0.0.1 only, and you switch access on in the Opir menu. Without it no client sees a thing.

Ideas to ask

What else you can hand over

A report for the customer

“Read the board’s table of groups and write an explanation for the customer: which lines, which breakers, what is on backup.”

Comparing versions

“Compare ‘Board v1’ and ‘Board v2’ and tell me what changed: parts, nets, values.”

A circuit from a description

“On a new sheet, build a 5 V regulator on an LM7805 with the capacitors from its datasheet.” Parts and nets by the assistant, wires by you.

Batch work

“Renumber the components in every schematic in the folder and check that no errors are left.”

Coursework notes

“Describe how the circuit works for my written report, referring to the designators.”

Netlist and SPICE

“Give me the SPICE netlist and prepare a model file to simulate this stage.”

Connecting

How to connect an AI app to Opir

  1. Turn access on

    Menu Opir → Allow AI Access (MCP). Access is off by default.

  2. Copy the configuration

    Opir → Settings… → External AI clients → Copy Client Configuration. The clipboard now holds a ready snippet with the exact path to the app.

  3. Paste it into the client

    Claude Desktop: add the snippet to claude_desktop_config.json and restart the app. Claude Code: one command in Terminal, claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp.

  4. Check

    Open a schematic in Opir and ask the client: “Which documents are open in Opir?” It should name yours.

Other clients, manual setup and what to do if it doesn’t work: see MCP setup.

Honestly

Worth knowing

The schematic the client works with goes to that client’s model: with a cloud service, to its servers. The client doesn’t lay wires; it joins pins into nets, and you draw, or use Route Net. It doesn’t make up symbols: if a part is missing from the library, it says what is missing.
