Схема — частина вашої розмови з ШІ

Вбудований асистент Opir бачить відкритий документ. Зовнішній застосунок бачить більше: кілька документів, файли на диску й інші свої інструменти.

Ваша підписка й ваша модель

Працюйте з Claude, за який уже платите, у Claude Desktop чи Claude Code: окремий ключ API в Opir для цього не потрібен.

Багато документів разом

Помічник відкриває файли .opir на диску, навіть коли Opir закрито: пройтися по папці, перевірити всі схеми, звести спільний перелік.

Разом з іншими інструментами

У тій самій розмові — те, що вміє ваш клієнт: пошук у мережі, таблиці, файли, інші сервери MCP. Знайти деталь, звести закупівлю, написати записку за схемою.

Правки видно одразу

Зміни з’являються у відкритому документі. Змінене підсвічується, кожен виклик — один крок скасування: ⌘Z повертає як було.

Кілька помічників разом

Вбудований асистент і зовнішні клієнти, підключені одночасно, дізнаються про правки одне одного.

Тільки на вашому Mac

Сервер слухає лише 127.0.0.1, а доступ вмикаєте ви — у меню «Опір». Без цього жоден клієнт схеми не побачить.

Приклад

Шість схем, одна розмова

Справжній запуск через Claude Code над демо-схемами з цього сайту: помічник сам знайшов файли, перевірив кожну схему, прочитав перелік елементів і звів закупівлю. Тринадцять викликів інструментів Opir, Opir при цьому навіть не відкривали.

ВиУ папці «Схеми» шість моїх проєктів. Перевір кожен і склади спільний список резисторів для замовлення.

Підключення

Як підключити ШІ-застосунок до Opir

  1. Увімкніть доступ

    Меню Опір → Дозволити доступ ШІ (MCP). Типово доступ вимкнено.

  2. Скопіюйте конфігурацію

    Опір → Параметри… → Зовнішні ШІ-клієнти → Скопіювати конфігурацію для клієнта. У буфері — готовий фрагмент із точним шляхом до програми.

  3. Вставте в клієнт

    Claude Desktop: допишіть фрагмент у claude_desktop_config.json і перезапустіть програму. Claude Code: одна команда в терміналі — claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp.

  4. Перевірте

    Відкрийте схему в Opir і спитайте клієнта: «Які документи відкриті в Opir?» Він має назвати ваш документ.

Інші клієнти, ручне налаштування й що робити, якщо не працює, — на сторінці Налаштування MCP.

Чесно

Що варто знати

Схему, з якою працює клієнт, отримує модель цього клієнта: з хмарним сервісом вона йде на його сервери. Проводи клієнт не прокладає — він з’єднує виводи мережами, а креслите ви або команда «Розвести мережу». Символів він не вигадує: якщо деталі немає в бібліотеці, скаже, чого бракує.
