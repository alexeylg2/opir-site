Приватность

Что Opir знает о вас

Коротко: ничего лишнего. В приложении нет рекламы, счётчиков и сбора статистики.

Что остаётся на вашем компьютере

  • Документы. Схемы — это файлы .opir там, где вы их сохранили. Прикреплённые даташиты лежат внутри документа.
  • Разговоры с ассистентом. Хранятся отдельно от документа, в папке приложения на вашем Mac.
  • Ключ API. Хранится в связке ключей macOS.
  • Ваша библиотека. Собственные компоненты и формы рамок — в папке приложения.

Что и куда отправляется

Только когда вы спрашиваете ассистента — и только к модели, которую вы выбрали.

К запросу добавляются ваше сообщение, описание схемы (детали, сети, результаты проверки) и, если это включено в настройках, изображение листа. Если ассистент читает даташит, его страницы тоже идут к модели.

  • Онлайн-сервис — на ваш выбор Anthropic (Claude), OpenAI или сервис, совместимый с API OpenAI: данные идут на серверы этого сервиса и обрабатываются по его правилам. Ключ и тариф — ваши.
  • Сначала — ваше разрешение. Перед первым запросом к онлайн-сервису Opir спрашивает разрешения и называет, что уйдёт: ваши сообщения, схема, изображения листов, приложенные картинки и даташиты. Отозвать разрешение можно в Настройки → Ассистент → Отправка в сервис → Отозвать.
  • Локальная модель (LM Studio, Ollama): запрос не покидает вашего компьютера.
  • Без ассистента приложение никуда ничего не отправляет.

MCP

Доступ для внешних клиентов по умолчанию выключен. Включённый сервер слушает только 127.0.0.1. Что клиент делает со схемой дальше — определяет сам клиент и его модель.

Обновления

Копия, скачанная с opir.dev, раз в сутки — если вы согласились на это при втором запуске — запрашивает список версий https://opir.dev/appcast.xml, а новую версию скачивает с GitHub Releases (github.com/alexeylg2/opir-site). Ничего, кроме обычного сетевого запроса, при этом не передаётся. Копию из Mac App Store обновляет сам App Store: Opir для этого никуда не обращается.

Этот сайт

Сайт статический: без куки, без счётчиков и сторонних скриптов. Он размещён на GitHub Pages; GitHub, как любой хостинг, видит технические данные запроса, в том числе IP-адрес.
