Claude Desktop, Claude Code и другие клиенты MCP

Ваше ИИ-приложение
работает прямо с Opir.

В Opir встроен сервер MCP. Через него Claude Desktop, Claude Code или другое приложение, которое умеет MCP, видит ваши схемы и работает с ними: читает, проверяет, меняет, сводит несколько документов вместе — в привычном разговоре.

Схема — часть вашего разговора с ИИ

Встроенный ассистент Opir видит открытый документ. Внешнее приложение видит больше: несколько документов, файлы на диске и другие свои инструменты.

Ваша подписка и ваша модель

Работайте с Claude, за который уже платите, в Claude Desktop или Claude Code: отдельный ключ API в Opir для этого не нужен.

Много документов вместе

Помощник открывает файлы .opir на диске, даже когда Opir закрыт: пройтись по папке, проверить все схемы, свести общий перечень.

Вместе с другими инструментами

В том же разговоре — то, что умеет ваш клиент: поиск в сети, таблицы, файлы, другие серверы MCP. Найти деталь, свести закупку, написать записку по схеме.

Правки видно сразу

Изменения появляются в открытом документе. Изменённое подсвечивается, каждый вызов — один шаг отмены: ⌘Z возвращает как было.

Несколько помощников вместе

Встроенный ассистент и внешние клиенты, подключённые одновременно, узнают о правках друг друга.

Только на вашем Mac

Сервер слушает только 127.0.0.1, а доступ включаете вы — в меню «Опір». Без этого ни один клиент схемы не увидит.

«Прочитай таблицу групп щита и напиши пояснение для заказчика: какие линии, какие автоматы, что на резерве.»

«Сравни “Щит v1” и “Щит v2” и скажи, что изменилось: детали, сети, номиналы.»

Схема по описанию

«Собери на новом листе стабилизатор 5 В на LM7805 с конденсаторами по даташиту.» Детали и сети — ассистент, провода — вы.

Пакетная работа

«Перенумеруй компоненты во всех схемах папки и проверь, не осталось ли ошибок.»

Записка к курсовому

Netlist и SPICE

«Выдай netlist для SPICE и подготовь файл модели для симуляции этого каскада.»

Подключение

Как подключить ИИ-приложение к Opir

  1. Включите доступ

    Меню Опір → Разрешить доступ ИИ (MCP). По умолчанию доступ выключен.

  2. Скопируйте конфигурацию

    Опір → Настройки… → Внешние ИИ-клиенты → Скопировать конфигурацию для клиента. В буфере — готовый фрагмент с точным путём к программе.

  3. Вставьте в клиент

    Claude Desktop: допишите фрагмент в claude_desktop_config.json и перезапустите программу. Claude Code: одна команда в терминале — claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp.

  4. Проверьте

    Откройте схему в Opir и спросите клиента: «Какие документы открыты в Opir?» Он должен назвать ваш документ.

Другие клиенты, ручная настройка и что делать, если не работает, — на странице Настройка MCP.

Честно

Что стоит знать

Схему, с которой работает клиент, получает модель этого клиента: с облачным сервисом она уходит на его серверы. Провода клиент не прокладывает — он соединяет выводы сетями, а чертите вы или команда «Развести сеть». Символов он не выдумывает: если детали нет в библиотеке, скажет, чего не хватает.
