MCP

Подключение внешнего ассистента

В Opir встроен сервер MCP. Через него Claude Desktop, Claude Code или другой клиент видит открытую схему и может её менять — так же, как встроенный ассистент.

Что для этого нужно

  • Opir запущен, и в меню Опір включено «Разрешить доступ ИИ (MCP)». По умолчанию доступ выключен.
  • Клиент, который умеет MCP через stdio: Claude Desktop, Claude Code и другие.

Сервер слушает только 127.0.0.1 — до него не добраться из сети. Клиент запускает маленькую программу opir mcp, а она передаёт запросы приложению.

Шаги

  1. Включите доступ

    Меню Опір → Разрешить доступ ИИ (MCP). Тот же переключатель есть в настройках, в разделе «Внешние ИИ-клиенты».

  2. Добавьте сервер в клиент

    Проще всего — кнопкой в приложении: Опір → Настройки… → Внешние ИИ-клиенты → Скопировать конфигурацию для клиента. В буфере окажется готовый JSON для клиента, с точным путём к opir, даже если приложение лежит не в «Программах». Вставьте его в настройки клиента.

    Или вручную.

    Claude Code — одна команда в терминале:

    claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp

    Claude Desktop — допишите в файл ~/Library/Application Support/Claude/claude_desktop_config.json:

    {
  "mcpServers": {
    "opir": {
      "command": "/Applications/Opir.app/Contents/Helpers/opir",
      "args": ["mcp"]
    }
  }
}

    После этого перезапустите клиент.

  3. Проверьте

    Откройте схему в Opir и попросите клиента: «Какие документы открыты в Opir?». Он должен назвать ваш документ.

Что умеет клиент

Читает

Схему с деталями, выводами и сетями; результаты проверки; изображение листа; список соединений; перечень элементов; таблицу групп щита; даташит детали.

Меняет

Добавляет и переставляет детали, соединяет выводы сетями, называет сети, задаёт сечения и цвета проводов, добавляет листы, перечень и таблицу групп.

Правила игры

  • Каждый вызов — один шаг отмены. Изменённое подсвечивается на листе; ⌘Z возвращает как было.
  • Провода чертит человек. Клиент соединяет выводы сетями, их видно пунктиром. Провести — вручную или командой «Развести сеть».
  • Символов клиент не выдумывает. Если в библиотеке нет нужной детали, он называет, чего не хватает, а не рисует замену.
  • О чужих правках он узнаёт. Если схему между его вызовами изменили вы, встроенный ассистент или другой ИИ-клиент, подключённый одновременно, следующий ответ сервера начинается с перечня изменений.
  • Файл на диске тоже годится. Клиент может работать с документом .opir по пути, даже когда приложение закрыто.

Если не работает

  • «Opir is not reachable» — приложение не запущено или доступ выключен в меню «Опір».
  • Клиент не видит сервера — проверьте путь к opir в настройках клиента и перезапустите его.
