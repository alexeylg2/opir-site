MCP

Підключення зовнішнього асистента

Opir має вбудований сервер MCP. Через нього Claude Desktop, Claude Code чи інший клієнт бачить відкриту схему і може її змінювати — так само, як вбудований асистент.

Що для цього треба

  • Opir запущено, і в меню Опір увімкнено «Дозволити доступ ШІ (MCP)». Типово доступ вимкнено.
  • Клієнт, який уміє MCP через stdio: Claude Desktop, Claude Code та інші.

Сервер слухає лише 127.0.0.1 — до нього не дістатися з мережі. Клієнт запускає маленьку програму opir mcp, а вона передає запити застосунку.

Кроки

  1. Увімкніть доступ

    Меню Опір → Дозволити доступ ШІ (MCP). Той самий перемикач є в параметрах, у розділі «Зовнішні ШІ-клієнти».

  2. Додайте сервер у клієнт

    Найпростіше — кнопкою в застосунку: Опір → Параметри… → Зовнішні ШІ-клієнти → Скопіювати конфігурацію для клієнта. У буфері опиниться готовий JSON для клієнта, з точним шляхом до opir, навіть якщо застосунок лежить не в «Програмах». Вставте його в налаштування клієнта.

    Або вручну.

    Claude Code — одна команда в терміналі:

    claude mcp add opir -- /Applications/Opir.app/Contents/Helpers/opir mcp

    Claude Desktop — допишіть у файл ~/Library/Application Support/Claude/claude_desktop_config.json:

    {
  "mcpServers": {
    "opir": {
      "command": "/Applications/Opir.app/Contents/Helpers/opir",
      "args": ["mcp"]
    }
  }
}

    Після цього перезапустіть клієнт.

  3. Перевірте

    Відкрийте схему в Opir і попросіть клієнта: «Які документи відкриті в Opir?». Він має назвати ваш документ.

Що вміє клієнт

Читає

Схему з деталями, виводами й мережами; результати перевірки; зображення аркуша; список з’єднань; перелік елементів; таблицю груп щита; даташит деталі.

Змінює

Додає й переставляє деталі, з’єднує виводи мережами, називає мережі, задає перерізи й кольори проводів, додає аркуші, перелік і таблицю груп.

Правила гри

  • Кожен виклик — один крок скасування. Змінене підсвічується на аркуші; ⌘Z повертає як було.
  • Проводи креслить людина. Клієнт з’єднує виводи мережами, їх видно пунктиром. Провести — вручну або командою «Розвести мережу».
  • Символів клієнт не вигадує. Якщо в бібліотеці немає потрібної деталі, він називає, чого бракує, а не малює заміну.
  • Про чужі правки він дізнається. Якщо схему між його викликами змінили ви, вбудований асистент або інший ШІ-клієнт, підключений одночасно, наступна відповідь сервера починається з переліку змін.
  • Файл на диску теж годиться. Клієнт може працювати з документом .opir за шляхом, навіть коли застосунок закрито.

Якщо не працює

  • «Opir is not reachable» — застосунок не запущено або доступ вимкнено в меню «Опір».
  • Клієнт не бачить сервера — перевірте шлях до opir у налаштуваннях клієнта і перезапустіть його.
